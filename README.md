# Uncensored AI Link

**An AI platform focused on local models, customizable AI personalities, and flexible multi-model workflows.**

Uncensored AI Link is an Arctic Fox Cyber project exploring a more configurable AI experience. The project is intended to bring local AI models and custom assistant behaviour together in one platform.

> **Project status:** Early stage. The repository currently contains project documentation only; application source code and setup instructions have not yet been published.

## Project Goals

- **Local AI models** — work toward running supported models locally.
- **Custom personalities** — configure assistant behaviour and response style.
- **Multi-AI support** — bring multiple AI models or providers into one workflow.
- **User control** — make AI configuration more flexible and transparent.

These are project goals, not a claim that every feature is currently implemented.
